## Decisions
1. **Self-host Geist Sans** — Downloaded variable WOFF2 from Vercel repo, declared via `@font-face` in globals.css. Avoids `next/font/local` Turbopack bug.
2. **CSS animations replace framer-motion** — `@keyframes` with identical timing (0.85s, 1.05s delays) and easing. No dependency needed.
3. **Native scroll parallax** — `useEffect` scroll listener + `transform: translateY()` at 30% speed, then switches to `position: fixed` at 30vh threshold. Matches production behavior exactly.
4. **Zero debt maintained** — Only 3 runtime deps: next, react, react-dom. No framer-motion, no extra libraries.
