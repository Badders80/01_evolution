## Narrative
This session resolved the Cloud Functions 403 auth blocker. Root cause was the GCP org policy `iam.allowedPolicyMemberDomains` preventing `allUsers`/`allAuthenticatedUsers` bindings. Since service account keys are also blocked, the only path was Workload Identity Federation. Built WIF pool + Vercel OIDC provider, Cloud Run proxy, and Firebase Auth middleware on all CFs. Auth chain is: Vercel → WIF token exchange → Cloud Run proxy (holds identity token, forwards Firebase token) → Cloud Function (verifies Firebase token). Everything is deployed — the last step is enabling Vercel OIDC in the dashboard.
